# 🇸🇦 الأرشيف الشجري الزمني لخطابات وبيانات السيد علي الخامنئي (1979–2026)
### المستودع المصدري الرسمي للنصوص الكاملة للبحوث التاريخية والدراسات الإسلامية والذكاء الاصطناعي

---

## 📖 نبذة عن المشروع
يشتمل هذا المستودع على الأرشيف النصي الكامل والمرتب زمنياً لجميع الخطب والبيانات الرسمية لسماحة آية الله العظمى السيد علي الخامنئي، يغطي 47 عاماً ممتدة من عام 1979 حتى مطلع عام 2026 (1357 إلى 1404 هـ.ش). تم إعداد هذا الأرشيف وفق أعلى المعايير العلمية لتسهيل البحث الأكاديمي وتطوير خوارزميات معالجة اللغة الطبيعية والذكاء الاصطناعي.

---

## 🔍 سياسة سلامة البيانات وجودتها
- **النصوص الكاملة حصراً:** تم استبعاد جميع الملخصات الصحفية، والفقرات المقتطعة، والتقارير الإخبارية الموجزة لضمان توفير النص الكامل كما أُلقي.
- **استبعاد التحليلات الثانوية:** تم حذف كافة المقالات التحليلية الصادرة عن كُتّاب أو وسائل إعلام للاحتفاظ بالخطاب المباشر الأصلي دون أي تدخل تحريري.
- **اعتماد النسخة الأكمل والأوثق:** في حال وجود أكثر من رواية أو تسجيل لخطاب في يوم معين، تم اعتماد النسخة ذات الكثافة النصية الأعلى والمدعمة بالوثيقة الرسمية (ملف PDF الأصلي).

## 🗂️ الهيكلية التنظيمية للمجلدات
```text
data/
└── [السنة]/
    └── [الشهر]/
        └── [التاريخ]_[المعرف]_[عنوان_الخطاب]/
            ├── content.md        # النص الكامل بصيغة Markdown النظيفة
            ├── metadata.json     # البيانات الوصفية (التاريخ الشمسي والميلادي، الرابط المصدر)
            ├── original.html     # شفرة HTML الأصلية للتوثيق والتدقيق
            └── document.pdf      # وثيقة PDF الرسمية المنشورة إن وُجدت
```

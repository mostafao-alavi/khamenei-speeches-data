# 🇨🇳 阿亚图拉·哈梅内伊演讲与著作编年树状归档 (1979–2026)
### 面向计算语言学、历史研究与人工智能领域的官方全文语料库

---

## 📌 项目概述
本仓库收录了阿亚图拉·赛义德·阿里·哈梅内伊自1979年至2026年（伊朗历1357年至1404年）47年间发表的全部官方演讲、讲道和讲话的完整编年树状文本。该语料库采用国际开放科学标准构建，专为学术研究、历史分析及大语言模型（LLM）微调与检索增强生成（RAG）设计。

---

## 🛡️ 数据完整性与质量标准
- **严格收录完整全文：** 彻底剔除所有新闻摘要、节选和短讯，仅保留逐字讲话全文。
- **排除第三方评论：** 清洗掉所有评论文章、媒体分析及二手文献，确保原始史料的纯粹性与客观性。
- **最佳版本审计：** 若同一活动存在多个不同来源记录，系统自动选取字数最多且附有官方正式PDF文档的版本作为基准。

---

## 📁 目录层级结构
```text
data/
└── YYYY（年份）/
    └── MM（月份）/
        └── YYYYMMDD_id<ID>_<标题>/
            ├── content.md        # Markdown 格式的演讲完整文本
            ├── metadata.json     # 标准化元数据（公历及伊朗历日期、原文链接、字数等）
            ├── original.html     # 用于验证与审计的原始网页快照
            └── document.pdf      # 官方发布的PDF文档（若有）
```

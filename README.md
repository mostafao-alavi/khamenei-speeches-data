<a name="فارسی"></a>
## 🇮🇷 فارسی
### درباره مخزن
این مخزن شامل **آرشیو کامل، منظم و درختی** متن سخنرانی‌ها، خطبه‌ها و بیانات رسمی حضرت آیت‌الله سید علی خامنه‌ای در طول ۴۷ سال گذشته (از سال ۱۳۵۷ تا سال ۱۴۰۴) است.

### ویژگی‌های کلیدی
- **فقط متن کامل:** تمام خلاصه بیانات، گزیده‌ها، خبرها و تحلیل‌های متفرقه حذف شده و صرفاً نسخه تمام‌متن و اصیل سخنرانی نگهداری شده است.
- **تفکیک درختی:** ساختار فولدرها به‌صورت سال و ماه (`data/YYYY/MM/`) طراحی شده است.
- **محتوای هر سخنرانی:**
  - `content.md`: متن کامل بیانات در قالب Markdown تمیز
  - `metadata.json`: فراداده شامل تاریخ شمسی و میلادی، عنوان رسمی، شناسه و پیوند منبع
  - `original.html`: کد HTML اصلی جهت بررسی و اصالت‌سنجی
  - `document.pdf`: سند رسمی PDF در صورت وجود

<a name="english"></a>
## 🇬🇧 English
### Overview
This repository hosts the **complete chronological tree-structured text archive** of all official speeches and works of Ayatollah Seyyed Ali Khamenei from 1979 to 2026 (1357–1404 Solar Hijri).

### Highlights
- **Strictly Full Transcripts:** Editorial summaries, briefs, and secondary analysis are excluded to preserve 100% full-text fidelity.
- **Hierarchical Layout:** Organized chronologically as `data/YYYY/MM/<entry>/`.
- **Contents:** Clean Markdown text (`content.md`), detailed metadata (`metadata.json`), source HTML (`original.html`), and official publication PDF when available.
